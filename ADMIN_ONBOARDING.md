# StrawberrySMP - Admin Onboarding

Welcome! This guide is designed to help you quickly understand and manage the StrawberrySMP dashboard effectively.

## 1. Moderation Workflow
As an Administrator, you have total control over the server's user base.

### Approving New Players
1. Log in to the Dashboard.
2. Navigate to **Admin Panel**.
3. Select the **Approvals** tab.
4. You will see all pending registrations here.
5. Click **Approve** to grant full dashboard access, or **Reject/Ban** if the application doesn't meet community standards.

### Managing Existing Users
1. Go to the **Users** tab in the Admin Panel.
2. You can toggle roles (Player/Admin), change status (Pending/Approved/Rejected/Banned), or ban users permanently.
3. Use the **Award** icon to manage badges for special community members.

## 2. Marketplace & Economy
The marketplace runs on a secure, server-side transaction system.
*   **Audit Trail:** Use the **Trade History** page to review all marketplace operations.
*   **Notifications:** When an item sells, you (and the seller) will receive an instant notification.
*   **Maintenance:** The system automatically cleans up trade history older than 3 days and messages older than 1 day to keep the server lightweight.

## 3. Important Notes
*   **Security:** Never share your Supabase Admin keys. 
*   **Status Indicators:** Online status is tracked in real-time. If you don't see a green dot, ensure the user is actively using the dashboard.
*   **Moderation:** Always provide a reason when rejecting or banning a user so they have clear feedback on why they were moderated.

Need further assistance? Contact your developer.
